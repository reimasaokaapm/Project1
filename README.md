# LIFT LOG

メモ感覚で使える、シンプルな筋トレ記録アプリ（iPhone向け PWA）。

## できること
- PULL / PUSH / LEGS の3日をタブで切り替え。次にやる日を自動でおすすめ
- 種目カードをタップ → 重量・回数を ＋/− で入れて「記録する」
- ★の種目（BIG3）は **6回できたら次回 +5kg** を自動で反映（目標回数・上げ幅は種目ごとに変更可）
- 種目ごとの重量推移グラフと履歴
- いつものメモ形式で取り込み／書き出し、全データのバックアップ・復元
- オフラインでも動作。データは端末内（localStorage）に保存

## iPhone で使う
1. GitHub Pages で公開（Settings → Pages → Branch を選んで Save）
2. iPhone の Safari で公開URLを開く
3. 共有ボタン →「ホーム画面に追加」

## ローカルで試す
```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## メモの書式
```
種目名 重量 回数     ← 数字が2つなら「重量 回数」
種目名 重量          ← 数字が1つなら重量
種目名               ← 未記録
（空行で日を区切る）
```
